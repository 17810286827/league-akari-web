# 车队页面视觉语言切换为海克斯魔典风

车队周报（/weekly）与榜单中心（/leaderboards）原为「淡绿终端」风格（近黑底 + 柔和绿）。经五方案原型评审（电竞 HUD / 战报杂志 / 海克斯魔典 / 终端密度 / 轻卡圆角，以 `?variant=A~E` 切换评审），选定**海克斯魔典**：LoL 海克斯色板（深蓝 #0a1428 底 + 金 #c8aa6e 渐变 + 青 #0ac8b9 点缀）、Cinzel 碑刻体 + 楷体、符文装饰与金银铜名次徽章。选择理由：与产品主题（LoL 战绩工具）契合度最高，金蓝对比在深底上可读性最好；字号经两轮迭代放大确认（标题 6xl、正文 17-18px）。

## Considered Options

- **电竞 HUD**（Rajdhani/Bahnschrift 压缩体）：竞技面板感强，但与"周报/榜单"的庆典感弱
- **战报杂志**（衬线纸感）：可读性好，但浅色纸底与全站暗色主题反差过大
- **终端密度**（等宽 CRT）：信息密度最高，但装饰感与游戏主题不符
- **轻卡圆角**（浅色 SaaS）：最平易近人，但气质像通用后台

## Consequences

- 周报分享图（canvas PNG）同步采用海克斯皮，与页面视觉一致
- 色板进 `tailwind.css` @theme 令牌（`--color-hex-*`），页面只引用令牌，后续换肤只改令牌
- 金边面板/金渐变标题/名次徽章/符文分隔线抽为 `src/components/hex/` 共享组件，两页复用，新增车队页面遵循同一语言
- Cinzel 经 index.html 引入 Google Fonts（同 Russo One 先例），不可达时回退楷体，不阻塞渲染
